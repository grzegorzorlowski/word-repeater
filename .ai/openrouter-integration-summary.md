## Configuration Required

### Environment Variables

Create a `.env` file in the project root:

```env
# Required
OPENROUTER_API_KEY=your_api_key_here

# Optional (defaults to openai/gpt-4o-mini)
OPENROUTER_MODEL_NAME=openai/gpt-4o-mini
```

### Getting Started

1. **Obtain API Key:**
   - Visit https://openrouter.ai/keys
   - Create an account and generate an API key
   - Add credits to your account

2. **Configure Environment:**
   - Copy API key to `.env` file
   - Optionally set preferred model

3. **Restart Server:**
   - Restart development server for env changes to take effect

4. **Test Integration:**
   - POST to `/api/flashcards/generate` with text
   - Verify flashcards are generated by AI

## API Integration Details

### Request Flow

```
1. User POST /api/flashcards/generate { text, limit }
   ↓
2. API endpoint calls generateFlashcardsFromText()
   ↓
3. Service calls generateFlashcardsWithAI()
   ↓
4. AI service creates OpenRouter client
   ↓
5. OpenRouter API called with:
   - System message (educational content creator context)
   - User message (text + flashcard count request)
   - JSON schema (enforces question/answer structure)
   ↓
6. OpenRouter returns structured JSON
   ↓
7. AI service validates and extracts flashcards
   ↓
8. Service persists flashcards to database
   ↓
9. API returns generated flashcards to user
```

### OpenRouter Configuration

- **Endpoint:** `https://openrouter.ai/api/v1/chat/completions`
- **Default Model:** `openai/gpt-4o-mini`
- **Parameters:**
  - `temperature`: 0.7 (balanced creativity)
  - `max_tokens`: 2000 (sufficient for multiple flashcards)
  - `timeout`: 60000ms (60 seconds)
- **Response Format:** JSON Schema (strict mode)

### JSON Schema for Flashcards

```json
{
  "type": "json_schema",
  "json_schema": {
    "name": "FlashcardsResponse",
    "strict": true,
    "schema": {
      "flashcards": {
        "type": "array",
        "items": {
          "type": "object",
          "properties": {
            "question": { "type": "string" },
            "answer": { "type": "string" }
          },
          "required": ["question", "answer"]
        }
      }
    }
  }
}
```

## Troubleshooting

### Common Issues

1. **"OpenRouter API key is not configured"**
   - Solution: Add `OPENROUTER_API_KEY` to `.env` file

2. **"Authentication failed"**
   - Solution: Verify API key is correct and has credits

3. **"Rate limit exceeded"**
   - Solution: Wait or upgrade OpenRouter plan

4. **Slow responses**
   - Solution: Use faster model like `gpt-4o-mini`

5. **Low-quality flashcards**
   - Solution: Adjust prompt or try different model
